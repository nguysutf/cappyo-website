O Cappyo é um Recurso Educacional Aberto (REA) desenvolvido com o objetivo de tornar o aprendizado de SQL (Structured Query Language) mais acessível, interativo e divertido. Inspirada em plataformas de aprendizagem gamificada, como o Duolingo, a aplicação utiliza mecânicas de jogos para ensinar os fundamentos da linguagem SQL, permitindo que os usuários desenvolvam suas habilidades de consulta e manipulação de bancos de dados de maneira progressiva e prática.

A plataforma é estruturada para oferecer uma experiência de aprendizagem interativa, na qual os usuários avançam por diferentes lições e desafios, explorando conceitos como consultas com SELECT, filtragem de dados com WHERE, ordenação com ORDER BY, agregação de informações e relacionamentos entre tabelas com JOIN. Por meio de exercícios práticos, feedback imediato e progressão por níveis, o Cappyo incentiva a prática contínua e facilita a compreensão dos conceitos apresentados.

O público-alvo são estudantes iniciantes em tecnologia, programação e bancos de dados, além de pessoas interessadas em desenvolver suas habilidades em SQL. A proposta é proporcionar um ambiente de aprendizagem lúdico e acessível, no qual os conhecimentos teóricos sejam aplicados diretamente na resolução de desafios, tornando o estudo de bancos de dados mais dinâmico, intuitivo e motivador.
