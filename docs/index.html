1. Objetivo Geral

Desenvolver Recurso Educacional Aberto (REA) para o ensino introdutório de Structured Query Language (SQL), utilizando de uma plataforma web gamificada que combine materiais de ensino, exemplos e exercícios práticos executáveis diretamente do navegador.

O projeto busca apresentar conceitos de banco de dados e SQL de maneira simplificada, progressiva e lúdica, permitindo que pessoas sem experiência prévia na área possam ter contato com os conceitos tanto quanto com a escrita e execução de comandos SQL, diretamente de um website.

Matérias abordadas:

  • SQL Básico
  • Manipulação de dados
  • WHERE Avançado
  • Gerenciamento de Tabelas
  • JOIN

2. Objetivo Específico

Produzir Materiais Didáticos: Desenvolver materiais textuais e vídeo aulas sobre banco de dados e SQL utilizando linguagem simples e exemplos próximos de situações reais antes da trilha de exercícios correspondente.

Criar uma Trilha Progressiva de Aprendizagem: Organizar o conteúdo em módulos, lições e fases, fazendo com que novos conceitos sejam introduzidos gradualmente.

Desenvolver Exercícios Interativos: Criar diferentes formatos de questões, incluindo:

  • Seleção de alternativas;
  • Completar comandos SQL;
  • Organizar trechos de uma consulta;
  • Interpretar resultados;
  • Escrever consultas SQL completas;
  • Executar comandos em um ambiente de execução de SQL simulado.

Promover Aprendizado Lúdico: Utilizar de metodologias de ensino lúdico e mecânicas de gamificação, como XP, progresso de fases, níveis e vidas para tornar o processo de aprendizagem mais estimulante.

Divulgar o Conhecimento: Manter o projeto e seus materiais publicamente acessíveis, utilizando ferramentas e plataformas como Vercel, GitHub e GitHub Pages.

2.1. Conteúdo Textual

O conteúdo teórico de cada módulo (SQL Básico, Manipulação de Dados, WHERE Avançado, Gerenciamento de Tabelas e JOIN) será disponibilizado em formato de página web dentro da própria plataforma, com linguagem simplificada, exemplos práticos do cotidiano e progressão gradual de complexidade, antecedendo a trilha de exercícios correspondente a cada módulo.

2.2. Videoaulas (Pílulas de Conhecimento)

As videoaulas terão duração de 5 a 7 minutos cada, abordando de forma objetiva os conceitos de cada módulo antes da prática. Todos os vídeos contarão com legendas como recurso de acessibilidade, produzidas na etapa de edição (Sprints 7 e 8 do cronograma).

3. Tecnologias Utilizadas

Para viabilizar o desenvolvimento da plataforma, serão utilizadas as seguintes tecnologias:

  • Frontend: React com TypeScript, estilização em SCSS
  • Backend: TypeScript e Node.js
  • Hospedagem e Deploy: Vercel (aplicação) e GitHub Pages (documentação/landing page)
  • Versionamento e Gestão: GitHub (repositório) e Trello (gestão ágil das sprints)
